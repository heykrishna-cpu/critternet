### Project Description
CritterNet is a fictional internet speed tester that translates your broadband speed into hilariously precise animal kingdom units — Snails/min, Sloths/hr, Turtles/sec, Cheetahs/sec and more. It's a fully animated, sound-rich, interactive web experience built entirely with zero external dependencies using pure HTML, CSS, and JavaScript.

### The Problem (that doesn't exist)
Normal internet speed testers show you boring numbers like "47.3 Mbps" — but what does that even MEAN? Nobody knows. Nobody cares. What people REALLY need to know is: am I faster than a garden snail? Slower than a sleepy sloth? Can my router outrun a cheetah? These are the questions that keep us up at night.

### The Solution (that nobody asked for)
CritterNet solves this existential broadband crisis by running a 4-second dramatic speed experiment and translating your connection into the only measurement that matters — fictional animal speeds. Complete with a live speedometer, animated animal mascots that walk/hop/gallop across the screen, a Wi-Fi packet courier that trips and drops the signal, internet mood detection, an achievement trophy system, and a Web Audio API synthesizer that gives every animal its own unique voice. All for absolutely no practical reason whatsoever.

## Technical Details
### Technologies/Components Used
For Software:
- **Languages:** HTML5, Vanilla CSS, Vanilla JavaScript (ES Modules)
- **Frameworks:** None — zero dependencies, zero build tools
- **APIs Used:** Web Audio API (sound synthesis), Canvas API (particles & confetti), SVG (speedometer gauge)
- **Tools:** Node.js (static file server), Git

For Hardware:
- Any modern browser (Chrome, Edge, Firefox)
- A computer with speakers (for the animal sounds 🐆)
- No special hardware required
